# Code Review

## Required params
- file path or diff

## Steps
1. Read the changed files
2. Check for: bugs, security issues, performance problems, style violations
3. Verify error handling and edge cases
4. Suggest improvements with specific code examples
5. Summarize findings: critical / warning / suggestion

## Example
User: "Review my PR"
→ Read diff → analyze → report findings by severity
